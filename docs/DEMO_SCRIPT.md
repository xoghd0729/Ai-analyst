# 라이브 데모 시나리오 — 9분 (3 페르소나 × 3분)

> 사용 환경: 본인 노트북 로컬 (localhost:8000 + localhost:5173)
> 백업: 화면 녹화 영상 + 슬라이드 캡쳐
> 시연 도구: macOS의 Cmd+`+` 로 폰트 키워두기, 마우스 커서 강조 (Highlightning)

---

## 데모 전체 흐름 (총 9분)

```
[0:00~0:30] 인트로 — "이 시스템은 한 문장으로 X"
[0:30~3:30] 페르소나 ① 28세 윤지 (적립형)
[3:30~6:30] 페르소나 ② 42세 민호 (균형형)
[6:30~9:00] 페르소나 ③ 55세 영자 (인출형)
```

## 인트로 (30초)

> *"AI 현금흐름 운영체제는 '50세에 월 200만원 받으려면 지금 얼마를?'에 역산으로 답하는 시스템입니다.*
> *오늘은 세 명의 다른 사람에게 같은 시스템이 어떻게 다른 답을 주는지 보여드리겠습니다."*

**화면**: 메인 페이지 — 로고 + 입력 폼이 깔끔하게 보이는 상태

---

## 페르소나 ① 28세 윤지 — 적립형 (3분)

### 컨텍스트 한 문장 (15초)
> *"신입사원 윤지는 월 300만원을 적립할 여력이 있고, 50세에 월 200만원의 배당을 받고 싶어합니다."*

### 입력값
| 필드 | 값 |
|---|---|
| 나이 | 28 |
| 연봉 | 4,500만원 |
| 목표 월배당 | 200만원 |
| 투자금 | 1,000만원 |
| 월 적립금 | 300만원 |
| 위험성향 | 균형형 |
| 목표 FIRE 나이 | 50 |

### 시연 흐름 (2분)

**1단계 (30초) — 입력 + 추천 결과**
- 입력 폼 채우고 "추천 받기" 클릭
- 화면 전환 — 추천 종목 5~8개가 표 형태로 나타남
- 말할 내용:
  > *"시스템이 18단계 필터를 거쳐서 윤지에게 SCHD, KODEX 고배당, JEPI 등을 추천했습니다. 추천 이유까지 SHAP으로 설명되는 게 특징입니다."*

**2단계 (45초) — FIRE 타임라인**
- `CashflowMilestone` 컴포넌트로 스크롤
- 50세까지 진행 바 보여줌
- 말할 내용:
  > *"50세까지 22년 동안 이 추천대로 적립하면 P50 기준 월 187만원 배당, 90% 신뢰구간 152~225만원입니다. 목표 200만원의 93% 달성 확률입니다."*

**3단계 (45초) — Monte Carlo + 백테스팅**
- `MonteCarloChart` 슬라이드
- `BacktestChart` 슬라이드 → "21년 실제 데이터 검증"
- 말할 내용:
  > *"이 추천 조합을 2005~2024 실제 데이터로 돌려보면 CAGR 8.2%, Sortino 1.4. KOSPI보다 알파 +3.1%입니다."*

### 와우 포인트
- "추천 이유"가 사람 말로 나오는 부분 (SHAP → 한국어 변환)
- 신뢰구간 시각화 (회색 띠 + P50 굵은 선)

## 페르소나 ② 42세 민호 — 균형형 (3분)

### 컨텍스트 (15초)
> *"민호는 자녀 교육비도 들고 본인 은퇴도 준비해야 합니다. 자산은 1.5억, 추가 적립은 월 100만원이 한계입니다."*

### 입력값
| 필드 | 값 |
|---|---|
| 나이 | 42 |
| 연봉 | 8,000만원 |
| 목표 월배당 | 250만원 |
| 투자금 | 15,000만원 (1.5억) |
| 월 적립금 | 100만원 |
| 위험성향 | 보수형 |
| 목표 FIRE 나이 | 60 |

### 시연 흐름 (2분 30초)

**1단계 (40초) — 세금 경고**
- 추천 결과 → 세금 섹션으로 즉시 스크롤
- 말할 내용:
  > *"민호의 경우 추천대로 가면 연 배당 2,300만원이 됩니다. **금융소득종합과세 임계점 2,000만원을 초과합니다.**"*
- 화면: 세금 위험도 알람 (빨강 배지)
- 말할 내용:
  > *"시스템이 ISA 계좌로 800만원을 옮기라고 제안합니다. 그러면 연 47만원의 세금이 절약됩니다."*

**2단계 (40초) — 행동편향 진단**
- 행동편향 섹션 (`BehavioralFinanceFilter` 결과)
- 말할 내용:
  > *"민호가 입력한 정보에서 시스템이 '홈 바이어스 — 한국 종목 비중 67%로 글로벌 분산 부족'을 감지했습니다."*

**3단계 (40초) — 스트레스 테스트**
- 스트레스 테스트 결과 (2008, 2020 시나리오)
- 말할 내용:
  > *"2008 금융위기를 가정하면 포트폴리오가 -32% 빠지지만, 배당은 -8%만 감소합니다. 이게 배당 중심 투자의 강점입니다."*

### 와우 포인트
- 세금 경고가 자동으로 뜨는 순간
- 한국 ISA 4,000만원 한도(2026 신법)가 자연스럽게 활용됨

## 페르소나 ③ 55세 영자 — 인출형 (2분 30초)

### 컨텍스트 (15초)
> *"영자는 5억 자산을 가지고 즉시 은퇴해서 월 200만원 인출하려고 합니다."*

### 입력값
| 필드 | 값 |
|---|---|
| 나이 | 55 |
| 연봉 | 0 (은퇴) |
| 목표 월배당 | 200만원 |
| 투자금 | 50,000만원 (5억) |
| 월 적립금 | 0 |
| 위험성향 | 보수형 |
| 목표 FIRE 나이 | 55 (즉시) |

### 시연 흐름 (2분 15초)

**1단계 (45초) — 즉시 달성 가능**
- 추천 결과 표시
- 말할 내용:
  > *"5억으로 즉시 월 200만원 가능합니다. 4% 인출률 기준. 다만 시스템은 다른 시나리오를 제안합니다."*

**2단계 (45초) — 시퀀스 위험**
- 스트레스 테스트
- 말할 내용:
  > *"은퇴 직후 3년이 가장 위험한 '시퀀스 리스크' 구간입니다. 첫 3년 동안 시장이 -30% 빠지면 영자의 5억은 평생 다시 회복 못 합니다."*
- 화면: 인출 안전 시뮬레이션 (P10 케이스 = 87세에 자금 고갈)

**3단계 (45초) — 시스템 제안**
- 말할 내용:
  > *"시스템 제안은: 첫 5년만 월 150만원으로 시작 → 시장 회복 확인 후 200만원으로 상향. 이렇게 하면 P10 케이스에서도 95세까지 자금 유지됩니다."*
- 한국어 스토리텔링 메시지 강조

### 와우 포인트
- "단순 추천"이 아니라 "단계적 전략"을 주는 모습
- 시퀀스 리스크 같은 학술 개념을 일반인 언어로 설명

## 데모 사고 대응

### 케이스 1: API가 안 떠요
**대비**: 노트북에 두 번째 터미널 미리 `uvicorn` 실행 상태로 띄워두기.
**플랜 B**: 화면 녹화 영상으로 즉시 전환 ("실시간 환경 이슈로 녹화본 보여드립니다").

### 케이스 2: 추천 결과가 이상해요 (BROKEN만 나옴 등)
**대비**: 사전에 3개 페르소나 입력값 정확히 테스트 → 결과 캡쳐 PDF 백업.
**플랜 B**: 캡쳐 화면 보여주며 진행.

### 케이스 3: 차트가 안 그려져요
**대비**: 같은 데이터로 미리 만들어둔 정적 PNG 슬라이드 5장.
**플랜 B**: 슬라이드로 전환 ("UI 렌더링 이슈, 동일한 데이터의 정적 버전").

### 케이스 4: 인터넷이 안 돼요
**대비**: 백엔드는 로컬, 프론트는 `npm run dev`로 로컬 빌드. 외부 API 호출 캐시된 상태.
**플랜 B**: 와이파이 없어도 demo 완주 가능하도록 설계.
