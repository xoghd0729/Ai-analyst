발표 준비 — AI 현금흐름 운영체제 (Cashflow OS)

발표 10분 기준. 핵심은 "기술 설명 40 / 시연 60". 청중이 마지막에 기억할 한 문장:
"종목 위험을 미래 소득 위험으로 바꾼 소득 지속성 플랫폼."


─────────────────────────────────────────
1. 10분 시간 배분
─────────────────────────────────────────

| 구간 | 시간 | 슬라이드 | 핵심 메시지 |
|---|---|---|---|
| 문제 정의 | 1분 | 1~2 | 기존 서비스 4대 한계 → "50세에 월 200만원" 질문 |
| 시스템 구조 | 1분 | 3 | Pipe-and-Filter 20필터, FastAPI+React |
| 라이브 시연 | 3분 | 4 | 입력 → 대시보드 → 포트폴리오 → 생존확률 |
| 모델·검증 | 3분 | 5~7 | XGBoost PR-AUC 0.801 · Forward Backtest · SHAP |
| 기여점·결론 | 2분 | 8~11 | 위험 변환 · 비교표 · 44세 사례 |


─────────────────────────────────────────
2. 3분 시연 동선 (클릭 → 멘트)
─────────────────────────────────────────

[0:00] 입력 화면
  - 클릭: 25세 페르소나 선택 (또는 직접 입력)
  - 멘트: "25세, 월 50만원 투자, 목표 월배당 200만원으로 돌려보겠습니다."

[0:30] 결과 대시보드 (헤드라인)
  - 멘트: "시스템이 역산한 결과, 명목 기준 44세에 목표를 달성합니다."
  - (왜 44세?) "세후 수익률 6.4%, 적립금 연 7% 증액 가정의 시뮬레이션입니다.
    수익률을 3%로 낮추거나 적립을 고정하면 달성 나이가 늦어지는데,
    슬라이더로 가정을 바꾸면 즉시 재계산됩니다."  ← 가정 기반임을 먼저 밝힌다

[1:15] 추천 포트폴리오
  - 멘트: "각 종목이 월배당·배당성장·방어 중 어떤 역할을 맡는지 태그로 보여줍니다."

[1:50] 생존확률 / 상세 분석
  - 멘트: "이 포트폴리오의 월배당 소득이 장기간 유지될 확률입니다.
    종목별 삭감확률 + 섹터 상관충격 + Monte Carlo로 계산한 시뮬레이션 추정치입니다."
    ← '검증된 예측'이 아니라 '추정치'라고 정확히 표현

[2:30] (시간 남으면) 저장 / 변화 추적
  - 멘트: "로그인하면 포트폴리오를 저장하고, 지난 분석 대비 변화를 추적합니다."

리허설 규칙: 발표 직전 1회 미리 실행해 캐시를 데워둔다. 입력값은 미리 정해 둔다.


─────────────────────────────────────────
3. 예상 질문 6 + 30초 답변
─────────────────────────────────────────

Q1. 왜 XGBoost인가?
  "LR·RF·GBM·XGBoost를 동일 GroupKFold로 비교했습니다. 선형 모델 LR은 0.670,
   트리 앙상블은 모두 0.80 부근으로 수렴했고, 그중 XGBoost가 ROC-AUC 최상위에
   SHAP 호환·클래스 불균형 보정까지 우수해 채택했습니다."

Q2. 왜 PR-AUC를 썼나?
  "배당 삭감이 약 22%인 불균형 데이터라 정확도(Accuracy)는 다수 클래스에 속아
   무의미합니다. PR-AUC는 희귀한 '삭감' 사례를 얼마나 잡아내는지를 정직하게
   측정해 줍니다. 무작위 기준선 0.385 대비 0.801이면 의미 있는 수치입니다."

Q3. 생존확률 82%는 실제로 검증된 수치인가?  ← 가장 주의할 질문
  "종목 수준 삭감 예측은 GroupKFold와 Out-of-Time Forward Backtest로 검증했습니다.
   다만 포트폴리오 생존확률은 검증된 종목 삭감확률에 섹터 상관충격과 Monte Carlo를
   결합한 시뮬레이션 기반 추정치입니다. 검증된 예측값이 아니라 추정치임을 분명히
   구분하고 있고, 향후 블록 부트스트랩으로 검증력을 보강할 계획입니다."

Q4. AI는 어디에 쓰였나?
  "AI는 배당 삭감 예측(XGBoost + SHAP)에 사용됩니다. FIRE 역산·생존확률·세금·
   행동편향은 그 예측 결과를 활용하는 규칙 기반 의사결정 레이어입니다.
   즉 '예측은 AI, 설계는 시뮬레이터'인 하이브리드 구조입니다."

Q5. 44세는 어떤 가정인가?
  "세후 배당수익률 6.4%, 월 적립 연 7% 증액, 물가 2.5%를 가정한 시뮬레이션입니다.
   수익률이 3%거나 적립이 고정이면 달성 나이가 늦어지며, 시스템은 명목·실질 두
   기준을 모두 제공합니다. 단정이 아니라 가정 기반 추정임을 전제로 합니다."

Q6. 기존 서비스와 무엇이 다른가?
  "(8페이지 비교표) 증권사 앱과 Simply Safe Dividends는 목표 월배당 역산·포트폴리오
   생존확률·FIRE 역산이 없습니다. 본 시스템은 이를 하나로 통합해 '종목 위험'을
   '미래 소득 위험'으로 변환합니다. 이것이 단순 배당 추천기와의 차별점입니다."

(보너스) Q7. 데이터가 적지 않나?
  "배당 삭감 자체가 희귀 이벤트라 양성 표본 확보가 어렵습니다. DART 기반 자동 수집을
   구축해 30종목에서 210종목·1,679관측치까지 확장했고, 캡스톤 범위에서는 충분합니다.
   다만 현재는 한국 시장 중심이며 글로벌 서비스로 일반화하지는 않습니다."

4. 시연 리스크 대비 (백업)
─────────────────────────────────────────

서버 죽음 / API 오류 / 인터넷 끊김에 대비:
  - 발표용 화면 캡처 5장을 PPT 맨 뒤에 '숨김 슬라이드'로 넣어둔다
    (입력 / 결과 대시보드 / 추천 포트폴리오 / SHAP / 생존확률)
  - 시연이 막히면 즉시 "미리 캡처한 결과로 보여드리겠습니다"로 전환
  - 캡처는 보고서 4.3 [그림 4-3~4-10]과 동일 → 일석이조
  - 백엔드/프론트는 발표 전 미리 실행해 두고, 노트북 절전·화면보호기 해제
