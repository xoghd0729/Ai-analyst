## Phase 4 — ML 고도화

**목표**: 배당 위험 예측 모델의 실질적 검증 및 운영 체계 구축

- [ ] walk-forward 재실험 (temporal contamination 수정, 8-fold)
- [ ] 추세 피처 추가 (배당성향 3년 slope, FCF margin 추세)
- [ ] 모델 calibration (예측 확률 보정, reliability diagram)
- [ ] Concept drift 감지 (입력 분포 변화 모니터링)
- [ ] 모델 레지스트리 (버전별 성능 추적)
- [ ] 재학습 파이프라인 자동화

## Q&A 대응 요약

| 질문 | 답변 요지 |
|-----|---------|
| "왜 실시간 KRX를 안 붙였나요?" | 현재는 분석·계획 수립 MVP 단계. DART와 정적 캐시로 핵심 기능을 검증했으며, 실시간 데이터 계층은 Phase 2에서 별도 구현 예정. |
| "ML 예측 성능이 충분한가요?" | 1년 OOS ROC-AUC 0.56으로 개선 여지가 있음. 현재는 보조 신호로만 활용하며 walk-forward 재실험을 Phase 4 계획에 포함. |
| "Monte Carlo 99%를 믿어도 되나요?" | 설정된 시뮬레이션 조건에서의 유지 비율이며, 검증된 장기 예측 확률이 아님. 파라미터 실증 보정은 Phase 4에서 진행 예정. |
| "실제 투자에 쓸 수 있나요?" | 투자 참고용 분석 도구임. 실제 투자 결정은 사용자 책임이며, 모든 결과에 면책 고지 포함. 실제 서비스는 Phase 5의 규제 검토 후 가능. |
