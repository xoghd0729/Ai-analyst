# 학습 데이터 확장 — 로컬 실행 가이드

> DART API는 Cowork 샌드박스에서 차단되어 있어 **반드시 로컬(`~/ai-analyst/`)에서** 실행합니다.

## 무엇이 바뀌었나

| 항목 | 이전 | 이후 |
|---|---|---|
| 학습 대상 종목 | 43개 (ranking.csv) | **166개** (확장 seed) |
| 배당삭감(positive) 샘플 | ~77행 | seed에 삭감이력 종목 다수 포함 → 증가 예상 |
| 수집 대상 정의 | ranking.csv 고정 | `data/training_universe_expanded.csv` 우선 |

확장 seed 구성: universe_pass 65 + universe_reject 60(삭감/탈락 = 학습 핵심) + ranking 17 + 삭감이력 보강 24.

## 신규 피처 (이번에 함께 추가)

수집 시 다음 3개 피처가 자동으로 함께 계산·저장됩니다:
부채비율(%), 이자보상배율, 매출성장률(%). `train_kr_3class.py`는 컬럼이 있으면
자동으로 학습에 포함하고(하위 호환), 추론(SHAP)은 모델의 feature_names를
동적으로 읽으므로 코드 변경 없이 연결됩니다.

## 실행 순서 (김태홍님이 로컬에서 직접 실행할 부분)

```bash
cd ~/ai-analyst

# 1. DART API 키 확인 (.env)
grep DART_API_KEY .env

# 2. 확장 seed + 신규 피처 수집 (166종목 × 2013~2025, 수십 분 소요)
python build_dataset.py
#   → "[확장 seed 사용] .../training_universe_expanded.csv" 로그 확인
#   → data/dividend_dataset.csv / .xlsx 갱신 (debt_ratio 등 신규 컬럼 포함)

# 3. 클래스 균형 + 신규 피처 확인
python3 -c "import pandas as pd; d=pd.read_csv('data/dividend_dataset.csv'); print(d['dividend_cut'].value_counts()); print([c for c in ['debt_ratio','interest_coverage','revenue_yoy_pct'] if c in d.columns])"

# 4. 모델 재학습 (신규 데이터·피처 반영)
python train_kr_3class.py

# 5. 회귀 테스트
pytest tests/test_pipeline_runner.py -v
```

## 수집 후 권장 작업

1. **클래스 불균형 보정** — 삭감(1) 비율이 여전히 25% 미만이면 모델 학습 시
   `scale_pos_weight`(XGBoost) 또는 SMOTE로 보정. 데이터 자체를 복제하지 말 것.
2. **재학습** — 확장 데이터로 `models/kr_3class_model.pkl` 재생성 후
   `tests/test_pipeline_runner.py`로 회귀 확인.
3. **검증** — `data/dividend_dataset.xlsx`의 삭감통계 시트로 종목별 삭감연도 육안 확인
   (DPS 부호 오류·이상치 점검).

## 되돌리기

원본 스크립트는 `build_dataset.py.bak`로 백업됨.
seed를 끄려면 `data/training_universe_expanded.csv`를 다른 곳으로 옮기면 ranking.csv 방식으로 복귀.
