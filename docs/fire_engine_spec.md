# AI Cashflow OS — FIRE 엔진 계산 명세서

> 생성일: 2026-09-23  
> 대상 파일: `utils/fire_engine.py`, `api/pipeline/filters.py`  
> 목적: 3일차 산출물 — 계산 의미·가정·한계의 공식 정의

---

## 1. 계산 목적

이 엔진은 단순 자산 증식이 아니라 **배당 현금흐름 목표 달성 시점**을 분석한다.

| 계산 구간 | 목적 | 사용 수익률 |
|----------|------|------------|
| **역할 A** — 목표 원금 역산 | 목표 월배당을 달성하는 데 필요한 자산 규모 계산 | `avg_net_yield` (세후 배당수익률) |
| **역할 B** — 자산 누적 시뮬레이션 | 투자금 + 적립금이 언제 목표 원금에 도달하는지 추정 | `asset_growth_yield` (세후 총수익률) |

두 역할은 분리된다. 역할 A의 수익률을 높이면 필요 원금이 줄고, 역할 B의 수익률을 높이면 자산 누적 속도가 빨라진다.

---

## 2. 수익률 정의

### `avg_net_yield` — 세후 배당수익률 (역할 A)

```
세후 연간 배당금 / 투자 원금 × 100
≈ 4.2% (포트폴리오 구성에 따라 달라짐)
```

- 사용 위치: `required_principal = annual_target / r_yield`
- 이 값이 높을수록 같은 현금흐름 목표에 더 적은 원금이 필요하다.
- **자본차익(주가 상승)을 포함하지 않는다.**
- 근거: 배당 중심 FIRE에서는 자본차익을 실현 매도 없이 현금흐름화할 수 없기 때문에, 목표 원금 역산에 자본차익을 포함하면 필요 자산을 과소추정할 위험이 있다.

### `asset_growth_yield` — 세후 총수익률 (역할 B)

```
세후 배당수익률 + 세후 자본차익률
≈ 4.42% (avg_total_return_net 기준)
```

- 사용 위치: `portfolio = portfolio × (1 + r_growth_asset/12) + monthly`
- FIRE 달성 전 **자산 누적 구간**에서 배당 재투자와 자본차익이 함께 복리로 작용하는 효과를 반영한다.
- **주의**: 총수익률에는 배당 재투자 효과가 이미 포함되어 있다. `div_growth_rate`를 총수익률에 추가로 더하면 이중 계산이 된다.
- `asset_growth_yield=None`이면 하위 호환으로 `avg_net_yield`를 사용한다.

## 3. 인플레이션 처리 (CPI)

### 적용 공식

```
미래 명목 목표 월배당 = 현재 구매력 기준 목표 × (1 + CPI)^n
```

- `n`: 현재 나이부터 목표 FIRE 나이까지의 연수
- 기본값: `cpi_rate = 2.5%`

### 적용 위치와 범위

| 항목 | CPI 적용 여부 |
|------|-------------|
| 목표 월배당 (역할 A 입력) | ✅ 1회 적용 |
| 목표 원금 역산 | 목표 금액에 CPI 반영 후 역산 |
| 자산 누적 성장률 (역할 B) | ❌ 미적용 (독립) |
| 배당수익률 | ❌ 미적용 |

**이중 적용 없음**: CPI는 목표 금액 변환에만 사용하며, 자산 성장률에는 별도로 적용하지 않는다.

### 해석 예시

```
목표: 현재 구매력 기준 월 200만원
CPI: 2.5%, 기간: 10년

미래 명목 목표: 200 × (1.025)^10 ≈ 256만원

→ 10년 후에 월 256만원의 배당이 있어야
  오늘의 200만원과 같은 구매력을 유지할 수 있다.
```

## 4. 적립금 증가율

```python
annual_savings_growth: float = 0.0  # 기본값 0% (명시적 전달 원칙)
```

### 적용 방식 (방식 B — 연말 인상)

```
1년차: 월 100만원 × 12개월 적립
       연말: 다음 해 적립금 = 100 × (1 + 0.03) = 103만원
2년차: 월 103만원 × 12개월 적립
       연말: 다음 해 적립금 = 103 × 1.03 = 106.1만원
...
```

- 적용 위치: `_simulate_fire_age` 내부, 12개월 복리 루프 종료 후 `monthly *= (1 + r_savings_growth)`
- **적용 범위**: 역할 B 자산 누적 시뮬레이션에만 적용
- **비적용 범위**: 역할 A 목표 원금 역산에는 반영되지 않음

### 기본값 0% 유지 근거

- 사용자가 입력하지 않으면 월 적립금이 고정된 것으로 계산한다.
- 3%나 5%를 기본으로 넣으면 사용자 동의 없이 낙관적 결과를 만든다.
- "적립금 증가를 가정하지 않은 기준 시나리오"라고 표시하며, "보수적 시나리오"와 구분한다.
  (물가 상승 상황에서 명목 적립금 고정은 실질 저축 여력이 감소하는 효과가 있기 때문)

## 5. 미반영 요소

### `div_growth_rate` — 보수적 설계상 미사용

```python
div_growth_rate: float = 5.0  # 연 배당성장률 (%)
```

**현재 상태**: 파라미터로 전달받지만 실제 계산에 사용하지 않는다.

**이유**: 목표 원금 역산(`required_principal = annual_target / r_yield`)은 현재 시점의 배당수익률을 고정하여 보수적으로 계산한다. 배당 성장을 반영하면 더 낮은 원금으로 달성 가능해 보이지만, 미래 배당 성장이 보장되지 않으므로 보수적 가정을 유지한다.

**인터페이스 의미**: 향후 배당 성장 시나리오 분석 기능 확장을 위한 자리 표시자. 현재는 전달해도 결과에 영향 없음.

**주의**: 총수익률(`asset_growth_yield`)에 배당 재투자 효과가 이미 포함되어 있으므로, 추후 `div_growth_rate`를 구현할 때 총수익률과 중복 적용하지 않아야 한다.

### 시스템 범위 외

- **일반적인 총수익률 기반 은퇴 인출 전략**: 이 엔진은 배당 현금흐름 목표를 중심으로 하며, 자본 일부 매도를 통한 인출 전략(SWR 등)은 포함하지 않는다.
- **배당 삭감 위험의 직접 반영**: 목표 원금 계산에 배당 삭감 확률을 직접 반영하지 않는다. 배당 지속 가능성은 별도의 Survival 모델에서 분석한다.
- **환율 변동**: 해외 ETF의 환율 변동은 별도 FX Stress Test 모듈에서 다룬다.
- **세금 제도 변경**: 2026 세법 기준을 적용하며, 제도 변경 시 별도 반영 필요.

## 6. 결과 해석 기준

### 결과가 의미하는 것

```
특정 가정(배당수익률, 총수익률, CPI, 적립금 증가율) 하에서
현재 조건이 유지될 때의 추정 FIRE 달성 시점
```

### 결과가 의미하지 않는 것

```
- 실제 은퇴 시점 보장
- 미래 수익률이 가정과 동일할 것이라는 예측
- 배당금 수령이 보장되는 계획
- 세금·거래비용·리밸런싱 비용 최적화된 결과
```

### 결과 민감도 예시 (40세, 목표 50세, 투자 5000만원, 월 100만원)

| 배당수익률 | 자산성장률 | CPI | 필요원금 | 예상 FIRE |
|-----------|-----------|-----|---------|----------|
| 4.2% | 4.2% | 2.5% | 73,149만원 | 67세 |
| 4.2% | 4.42% | 2.5% | 73,149만원 | **66세** (현재 설정) |
| 5.0% | 4.42% | 2.5% | 61,445만원 | 63세 |
| 4.2% | 4.42% | 0% | 57,143만원 | 65세 |

→ CPI와 배당수익률 가정이 FIRE 시점에 가장 큰 영향을 준다.

## 7. 회귀 테스트 기준

| 테스트 케이스 | 기대 결과 |
|-------------|---------|
| `asset_growth_yield=None` | 기존 동작과 동일 ✅ |
| `asset_growth_yield=avg_net_yield` | 분리 전 결과와 동일 ✅ |
| `asset_growth_yield` 증가 시 | FIRE 나이 단조 감소 ✅ |
| `avg_net_yield` 변경, `asset_growth_yield` 고정 | 필요원금 변화, 자산 성장 경로 독립 ✅ |
| `div_growth_rate` 변경 | 결과에 영향 없음 (데드 파라미터) ✅ |
| `annual_savings_growth=3%` | 매 연말 적립금 3% 인상 적용 ✅ |
| CPI 이중 적용 확인 | 목표 금액에만 1회 적용 ✅ |

## 8. API 경로별 수익률 기준 요약

| 경로 | avg_net_yield 출처 | asset_growth_yield 출처 |
|------|-------------------|------------------------|
| `POST /recommend` → `fire_plan` | `ctx.avg_yield_net` (~4.2%) | `ctx.avg_total_return_net` (~4.42%) |
| `POST /recommend` → `reverse_fire` | `ctx.avg_yield_net` (~4.2%) | `ctx.avg_total_return_net` (~4.42%) |
| `POST /fire-reverse` (독립 API) | 요청값 `avg_net_yield` (기본 5.0%) | 요청값 `asset_growth_yield` (기본 None) |
| InteractiveSimulator → fire-reverse | `sum.avg_dividend_yield_net` | `sum.avg_total_return_net` |
| MiniProjection (클라이언트 간이) | — | `sum.avg_total_return_net` (단순 FV, CPI 미반영) |

> **MiniProjection 주의**: 단순 복리 FV 공식 사용, CPI와 배당 성장률 미반영.  
> 장기(10년+)일수록 공식 FIRE 결과와 차이가 커진다. "간이 추정치" 배지로 구분 표시 중.
